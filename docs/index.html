Setup Instructions
1
Flash Raspberry Pi OS Lite (64-bit) onto an SD card via Raspberry Pi Imager.
2
Boot the Pi, connect to your network, and SSH in: ssh pi@<pi-ip>
3
Run the one-line command above — Docker, NAS mounts, & systemd service auto-configure.
4
Open web dashboard at http://<pi-ip>:9000 to control playback & settings.
