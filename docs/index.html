High-performance digital slideshow and video engine for Raspberry Pi 4 & 5. Optimized for NAS storage stability, Google Photos integration, Home Assistant MQTT automation, and glassy web controls.

Quick Start & Installation

Bootstrap Installation

Flash Raspberry Pi OS Lite (64-bit, Trixie) via the Raspberry Pi Imager. Boot the Pi, SSH in, and run:

wget -qO- https://raw.githubusercontent.com/UnDadFeated/piTrove/main/install.sh | sudo bash

CLI & Utility Tools

pitrove config
Terminal configuration wizard (TUI) to adjust settings & MQTT.
pitrove logs
Stream rendering logic, database metrics, and loader threads.
pitrove restart
Restart the underlying Docker container safely.
sudo ./install.sh --update
Update package, download latest code, and rebuild binary.
sudo ./install.sh --organize [path]
Optional chronological sorting and date-prefixing utility. No longer required as the slideshow engine now automatically uses EXIF/filesystem date fallbacks for the seasonal window.

Media Playback & Formats

piTrove is designed from the ground up for seamless, high-fidelity playback of both high-resolution photography and hardware-accelerated video clips.

High-Res Photography

Native, multi-threaded image decoding utilizing hardware-accelerated color conversions. Displays pictures with professional-grade transitions, CRT vignette shaders, and color-matched blur backgrounds.

  • JPEG / JPG — Standard capture
  • PNG — Lossless graphics
  • WebP — Next-gen compression
  • HEIC / HEIF — Modern iOS format
  • TIFF / TIF — High-bit depth
  • BMP / TGA — Raw structures

Cinematic Video Engine

Interleaves video clips within your photo playlist. Leverages an optimized native subprocess linking the direct-to-framebuffer DRM/KMS hardware decoder.

  • MP4 / MKV / MOV — Formats
  • H.264 / AVC — Up to 1080p60
  • H.265 / HEVC — Up to 4K60
  • Dynamic Volume (0-150)
  • Aggressive buffering
  • Subtitle support (.srt)

System Capabilities

DRM/KMS Hardware Acceleration

Direct rendering to the GPU framebuffer via SDL3. Zero desktop environment or windowing overhead.

Interactive Web Settings & HUD

Premium glassmorphic dashboard to remote-control slideshow, tweak config values, and stream logs live.

Google Photos Cloud Sync

OAuth2-authenticated background sync daemon to download and cache images automatically.

Home Assistant MQTT Integration

Instant remote triggers, screen backlight control, play/pause switches, and motion wakers.

Cinematic Ken Burns Effect

Smooth, custom pan and zoom scaling animations returning fluidly to original dimensions.

Dynamic Bias Backlighting

Real-time edge sampling that casts soft color glows behind the screen to blend the frame with the wall.

On-This-Day & Content Filters

Year-agnostic seasonal calendar windows, intelligent animal/people classification, and document clutter skipping.

Resilient Storage & Cache

Linux getdents64 filesystem scanner preventing CIFS hangs, coupled with thread-safe SQLite3 WAL caching.

Touchscreen Interface & Navigation

Enable floating navigation overlays (Previous, Settings, Next) on touch, plus settings sliders, +/- adjusters, and a virtual keyboard modal directly on the screen.
