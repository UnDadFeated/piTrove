Installation & Setup

1

Flash OS

Install Raspberry Pi OS Lite (64-bit, Trixie). Enable SSH and Wi-Fi.

2

Bootstrap Installation

SSH into your Raspberry Pi and execute this single bootstrap command to automatically install Docker, mount NAS storage, and configure the background daemon:

wget -qO- https://raw.githubusercontent.com/UnDadFeated/piTrove/main/install.sh | sudo bash
3

Management CLI Commands

Manage your slideshow daemon instantly from the Pi command line using these utility wrappers:

pitrove config Interactive 10-tab terminal UI to configure NAS, MQTT, and Google Photos settings.
pitrove logs Stream active C++ slideshow logs, preload threads status, and loader updates.
pitrove restart Restart the underlying slideshow container service and re-read config values.
pitrove status Query container state, health diagnostics, and active memory allocation.

Built-in Archive Organizer

Maintain your library structure cleanly with piTrove's interactive media organizer wizard. Perfect for sorting files to work seamlessly with seasonal scanning rules.

Run the organizer:
sudo ./install.sh --organize /path/to/media
Chronological Sorting

Automatically structures loose photo and video archives into organized YYYY-MM month directories based on metadata or creation dates.

In-Place Prefixing & Dry-Runs

Add structured prefixes to file names safely. The dry-run feature lets you preview all proposed file changes before writing them to disk.

Seasonal Display Alignment

Ensures folder naming conventions line up with the year-agnostic seasonal scanning engine to display memories from the current time of year.

System Capabilities

DRM/KMS Hardware Acceleration

Zero windowing environment overhead, rendering directly to the GPU framebuffer via SDL3.
