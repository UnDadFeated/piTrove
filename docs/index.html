Professional-grade slideshow engine built for Raspberry Pi. Hardware-accelerated rendering, NAS storage, and smart home integration.

C++ · Docker · DRM/KMS · Raspberry Pi 4 & 5

Get started

One command. Fully containerized. Runs on boot.

$ wget -qO- https://raw.githubusercontent.com/UnDadFeated/piTrove/main/install.sh | sudo bash
  1. 1 Flash Raspberry Pi OS Lite 64-bit via the Pi Imager.
  2. 2 Boot the Pi, connect to your network, and SSH in.
  3. 3 Run the install command above. Docker, media mounts, and systemd unit are set up automatically.
  4. 4 Access the web dashboard at http://<pi-ip>:8080.

Built for reliability

Every component designed to run unattended for months without intervention.

DRM/KMS Rendering

Direct GPU framebuffer rendering via SDL3. No desktop environment required.

Docker Containerized

All dependencies isolated. Build once, run on Raspberry Pi 4 or 5.

NAS-Optimized I/O

Custom filesystem scanner with CIFS hang prevention for network storage.

Google Photos Sync

Background OAuth2 sync from your albums with configurable intervals.

Home Assistant MQTT

Auto-discovers as a smart home device with screen, skip, and motion controls.

Web Dashboard

Remote control with live telemetry, playback controls, settings, and log streaming.

Dashboard Preview

Interactive web remote for managing your frame.
