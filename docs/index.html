Get started

One command. Fully containerized. Runs on boot.

$ wget -qO- https://raw.githubusercontent.com/UnDadFeated/piTrove/main/install.sh | sudo bash
  1. Flash Raspberry Pi OS Lite 64-bit via the Pi Imager.
  2. Boot, connect to network, and SSH in: ssh pi@<pi-ip>
  3. Run the install command above — Docker, NAS mounts, and systemd unit are configured automatically.
  4. Access the web dashboard at http://<pi-ip>:9000.

Built for reliability

Every component designed to run unattended for months without intervention.

Media Engine

DRM/KMS GPU rendering via SDL3 with no desktop required. H.264/H.265/AV1 video playback with Pi 4/5 auto-detected hardware acceleration. JPEG, PNG, HEIC, WebP, TIFF support. Professional transitions, Ken Burns, bias lighting, and adaptive overlays.

Smart Scanning

NAS-optimized scanning with CIFS hang prevention. SQLite3 WAL persistence for zero redundant scans. Seasonal window filtering, On-This-Day anniversary matching, content filtering for documents, and multi-threaded async preloading.

Integrations

MQTT with Home Assistant auto-discovery for remote controls and motion sensing. Google Photos cloud sync. Glassmorphic web dashboard with live telemetry. Native touchscreen input via evdev.

System & Controls

11-category TUI configuration wizard. PIN-protected dashboard. Scheduled sleep/wake. Diagnostics HUD with real-time telemetry. Adaptive text contrast. OLED burn-in prevention. CLI management tool.

Reliability

Docker containerized isolation. Three-layer auto-recovery watchdog. Network monitoring with automatic Wi-Fi reset. Video stall detection with forced recovery. Async-signal-safe crash handlers. Daily zero-touch auto-updates.

Architecture

C++23 with SDL3, FFmpeg, SQLite3, and libexif. Multi-stage Docker builds. Runtime Pi 4/5 hardware detection. 40+ source modules with comprehensive error database and diagnostic codes.
