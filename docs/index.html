Get started

One command. Fully containerized. Runs on boot.

$ wget -qO- https://raw.githubusercontent.com/UnDadFeated/piTrove/main/install.sh | sudo bash
1 Flash Raspberry Pi OS Lite 64-bit via the Pi Imager.
2 Boot the Pi, connect to your network, and SSH in.
3 Run the install command above. Docker, media mounts, and systemd unit are set up automatically.
4 Access the web dashboard at http://<pi-ip>:8080.
