Built for reliability

Every component designed to run unattended for months without intervention.

⚡

DRM/KMS Rendering

Direct GPU framebuffer rendering via SDL3. No desktop environment required—just raw performance on the Pi.

◆

Docker Containerized

All dependencies isolated. Build once, run anywhere on Raspberry Pi 4 or 5 with Trixie Lite.

🖋

NAS-Optimized I/O

Custom getdents64 scanner with CIFS hang prevention. Your media on network storage, no lockups.

☁

Google Photos Sync

Background OAuth2 sync from your albums. Configurable interval and local cache directory.

🏠

Home Assistant MQTT

Auto-discovers as a smart home device. Screen on/off, skip, play/pause, and motion-based waking.

🎨

Cinematic Presentation

Ken Burns pans, crossfade transitions, color-matched matte borders, and ambient bias backlighting.

Get started

Flash Raspberry Pi OS Lite 64-bit, boot the Pi, and run one command.

$ wget -qO- https://raw.githubusercontent.com/UnDadFeated/piTrove/main/install.sh | sudo bash
