Setup Instructions
1
Flash Raspberry Pi OS Lite (64-bit) onto an SD card via Raspberry Pi Imager.
2
Boot the Pi, connect to network, & SSH in: ssh pi@<pi-ip>
3
Run the 1-line command above — Docker, NAS mounts, & service auto-configure.
4
Access web dashboard at http://<pi-ip>:9000 to control playback.
