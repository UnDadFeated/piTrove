Engineered for Reliability and Elegance

Unlike generic scripts, piTrove runs inside a containerized sandbox with native C++ SDL3 rendering and custom kernel-level display probing.

DRM/KMS Rendering

Bypasses X11 and Wayland entirely. Operates directly on the GPU framebuffer for maximum performance and low thermal output.

Network Resilient

Specialized low-level I/O prevents file-locking & CIFS hangs. Safeguards the cache against corruption during NAS dropouts.

Docker Orchestrated

Absolute dependency isolation. Runs safely as a systemd-controlled container with read-only root security.

Twin-Portrait Collage

Intelligently groups adjacent vertical photos to display them side-by-side with dynamic, harmonious borders.

Smart Home Native

MQTT Auto-Discovery registers entities inside Home Assistant. Integrates sleep modes with motion detectors.

Google Photos Sync

Direct album synchronization with background downloads and automated OAuth2 token rotation.

Simple 3-Step Setup

Get your digital picture frame up and running on Raspberry Pi OS in minutes.

1

Flash Raspberry Pi OS

Flash the official 64-bit Lite image using Raspberry Pi Imager. Enable SSH and Wi-Fi.

2

Run Bootstrap Installer

SSH into your Pi and execute the one-command installer. It will automatically compile, configure local mounts, and register the systemd background daemon.

3

Configure Settings

Run pitrove config anytime to access the interactive 10-tab configuration wizard to setup MQTT, NAS credentials, and Google Photos.
