Containerized Digital Picture Frame

High-performance slideshow engine for Raspberry Pi 4 & 5. Optimized for NAS storage stability, Google Photos integration, and Home Assistant MQTT automation.

Get Started
Run this command in terminal on a fresh Raspberry Pi OS (64-bit):
wget -qO- https://raw.githubusercontent.com/UnDadFeated/piTrove/main/install.sh | sudo bash

Installation

1

Flash OS

Install Raspberry Pi OS Lite (64-bit). Enable SSH and Wi-Fi.

2

Bootstrap

SSH in and run the quick bootstrap command shown above.

3

Configure

Run pitrove config for the TUI configuration menu.

Capabilities

DRM/KMS Hardware Acceleration

Zero windowing environment overhead, rendering directly to the GPU framebuffer via SDL3.

NAS Mount Resilience

Prevents CIFS hangs and stops corrupt DB caching flags during transient drops.

Home Assistant MQTT integration

Auto-discovery discovery, remote slideshow skip/toggles, and motion sensor wake-ups.

Google Photos sync

Background album download client with automated OAuth2 rotation.
