# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in piTrove, please report it privately by creating a [Security Advisory](https://github.com/UnDadFeated/piTrove/security/advisories/new).

Please **do not** report security vulnerabilities via public GitHub issues or discussions.

## What to Include

- A clear description of the vulnerability
- Steps to reproduce it
- Potential impact
- Any suggested fix (if known)

## Response

I aim to respond within 48 hours and will work to address confirmed vulnerabilities as quickly as possible.
