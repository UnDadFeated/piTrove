# TODO - piTrove Bug Tracking

This file tracks identified bugs, errors, and architectural weaknesses in the piTrove codebase. All previously resolved items have been cleared to maintain focus on the active backlog.

## Active Backlog (Audit Results)

The following bugs and architectural weaknesses are currently open in the codebase:

| ID | Component | Severity | Description & Proposed Fix | Breakage Risk | Status |
|---|---|---|---|---|---|
| 17 | mqtt.cpp | High | **Shutdown race / Undefined behavior**<br>`stop_mqtt_client` calls `pclose(g_mqtt_fp)` on the main thread while the subscriber thread is blocked on `fgets` using the same pointer. This causes a data race on the `FILE` handle and undefined behavior (crashes or hangs).<br>*Fix:* Use `fork` + `exec` directly to track the child PID and send `SIGTERM` before closing the file descriptor, avoiding shared handle state. | Low | [ ] Deferred |
| 22 | util.cpp | Medium | **Blocking getaddrinfo on main thread**<br>`is_nas_online()` performs a blocking DNS lookup via `getaddrinfo()`. If DNS is offline/slow, the main rendering thread will freeze for up to 60 seconds.<br>*Fix:* Run the DNS lookup in a background thread or check local network interface gate status first. | Medium | [ ] Deferred |
| 28 | config.cpp | Low | **Dead code setting**<br>The global configuration parameter `rotation` is parsed and stored, but completely ignored by the Modesetting KMSDRM rendering pipeline.<br>*Fix:* Document this as dead code or implement rotation in Modesetting DRM. | Low | [ ] Deferred |
| 40 | image_loader.cpp | Medium | **Potential division by zero in edge average calculations**<br>In `image_loader.cpp`, the edge average color calculations divide by `ac` or `bot_samples`. If `sw` or `sh` is zero or less than 3, `ac` or `bot_samples` can remain 0, leading to a division-by-zero crash.<br>*Fix:* Guard the division: `if (ac > 0) ...` and check image dimensions before edge parsing. | None | [ ] Proposed |
| 41 | preload.cpp | Medium | **Potential division by zero in preload edge calculation**<br>In `preload.cpp`'s `compute_edge_data`, division by `ns` or `sample_count` is done without checking if they are 0. If `w` or `h` is 0, a crash will occur.<br>*Fix:* Guard the divisions: `if (ns > 0)` and `if (sample_count > 0)`. | None | [ ] Proposed |
| 42 | organizer.cpp | Medium | **Filesystem scan crash on network share disconnects**<br>`organizer.cpp` uses standard filesystem calls like `fs::exists(dest_path)` inside the scan loop. If target NAS is offline or drops connection, this throws a `filesystem_error` exception, aborting the entire scan.<br>*Fix:* Use the non-throwing overload `fs::exists(dest_path, ec)` and handle errors gracefully. | None | [ ] Proposed |
| 43 | cache.cpp | Low | **Unsafe prepared statement string bindings**<br>`CacheManager::upsert` and `load_cached` bind strings using `SQLITE_STATIC`. If the string references are modified or go out of scope before execution finishes, it can cause database corruption or use-after-free bugs.<br>*Fix:* Transition to `SQLITE_TRANSIENT` to force SQLite to make its own copy of the string contents. | Low | [ ] Proposed |
| 44 | scanner.cpp | Low | **Unchecked localtime_r return value**<br>In `MediaScanner::is_month_in_window`, `now` is dereferenced directly: `now->tm_mon`. If `localtime_r` fails and returns `nullptr`, this causes an immediate null pointer dereference crash.<br>*Fix:* Add `if (!now) return true;` guard check right after `localtime_r`. | None | [ ] Proposed |
| 45 | http_server.cpp | Medium | **Hanging client threads on shutdown deadlock**<br>`stop_http_server()` attempts to synchronously join all client connection threads (`g_http_client_threads`). If a client connection is slow or hung, the client thread remains blocked on socket I/O, deadlocking the app shutdown process.<br>*Fix:* Maintain a thread-safe registry of active client FDs and call `shutdown(fd, SHUT_RDWR)` on all of them during `stop_http_server` to unblock pending reads. | Low | [ ] Proposed |
| 46 | http_server.cpp / google_photos.cpp | Low | **Fragile JSON parsing for escaped quotes**<br>`parse_json_value` finds the end of a string value by locating the next quote character. If a JSON value contains escaped quotes (e.g., `\"`), it incorrectly truncates the value or fails to parse.<br>*Fix:* Skip over escaped quote characters when scanning for string boundaries. | Low | [ ] Proposed |
| 47 | google_photos.cpp | Low | **Bypassed security check if URL contains explicit port**<br>The host domain check parses the download URL's host. If Google returns a URL containing a port (e.g. `googleusercontent.com:443`), the domain validation fails because the string doesn't match exactly.<br>*Fix:* Strip the port number from the extracted host string before validation. | None | [ ] Proposed |
| 48 | transition.cpp | Low | **Modulo-by-zero crash in transition rendering**<br>In `render_dissolve` and `render_pixelate`, calculations use `modulo` operations: `(seed >> 16) % screen_w`. If the graphics window is minimized, resized to 0, or loses device context, this triggers a division-by-zero crash.<br>*Fix:* Guard calculations: `if (screen_w > 0 && screen_h > 0)`. | None | [ ] Proposed |
| 49 | main.cpp | Low | **Insecure host config path fallbacks inside container**<br>`main.cpp` defaults the TOML configuration path candidate search to `/home/pi/piTrove/src/config/config.toml` if not supplied. This path does not exist in the minimal container environment, causing start/load failures if CLI flags are omitted.<br>*Fix:* Add `/app/config/config.toml` and `./config/config.toml` to candidates. | None | [ ] Proposed |
| 50 | main.cpp | Low | **Fragile single-instance lock file location**<br>The lock file `piTrove.lock` is created in `/app/piTrove.lock`. If the app directory is mounted read-only or locks are not supported on the target filesystem, the app will fail to start.<br>*Fix:* Allow overriding via environment variables or fall back to `/tmp/piTrove.lock`. | None | [ ] Proposed |
| 51 | font_render.cpp | Low | **Hardcoded system font fallbacks**<br>`load_font` includes system fallbacks like `/usr/share/fonts/...` which are typically missing inside minimal Docker container runtime images.<br>*Fix:* Verify bundled font assets are located under the `/app/src/fonts/` directory first. | None | [ ] Proposed |
| 52 | http_server.cpp | Low | **Resource leak on invalid Content-Length**<br>In `handle_client`, if a client sends an HTTP header with an extremely large `Content-Length` but never sends data, resources might remain allocated during timeout.<br>*Fix:* Set a strict maximum header and body size limit before reading. | None | [ ] Proposed |
| 53 | main.cpp / util.cpp | Low | **Race condition in error code updates**<br>`trigger_error` writes to `g_active_error_code` without thread synchronization. Concurrently running threads can overwrite reported diagnostics codes, causing the UI to show only the last reported error.<br>*Fix:* Implement thread-safe diagnostics collection or log all errors to a concurrent thread-safe collection. | Low | [ ] Proposed |
| 54 | preload.cpp | Low | **Potential division by zero in average color calculation**<br>In `compute_average_color`, if `samples` count ends up at zero, it is protected via `if (samples == 0)`, but loop increments can underflow/overflow if image width/height are extremely small.<br>*Fix:* Guard the inner calculations and bounds clamping explicitly. | None | [ ] Proposed |
| 55 | main.cpp / util.cpp | Low | **Privileged host reboot command failure**<br>Automatic network recovery reboots try to execute reboot shell commands. If run inside a container with limited capabilities, `sudo` commands fail, causing the keepalive reboot to hang.<br>*Fix:* Log failure to reboot and implement alternative shutdown commands. | None | [ ] Proposed |
| 56 | util.cpp | Low | **Stale socket descriptors on NAS check failure**<br>In `is_nas_online()`, if `getaddrinfo` fails or early connection returns, the code has multiple exit branches. Some branches could leak intermediate socket variables if refactored.<br>*Fix:* Ensure socket resource cleanup using standard RAII guards. | None | [ ] Proposed |
| 57 | http_server.cpp | Low | **Unchecked setsockopt timeout return values**<br>`setsockopt` timeout configuration is set, but the return value is only logged on warning. If the system fails to set it, sockets remain blockable forever.<br>*Fix:* Validate setsockopt returns and fallback to manual select/poll if failed. | None | [ ] Proposed |
| 58 | util.cpp | Low | **Logging thread mutex contention bottleneck**<br>Every log line locks `queue_mtx` globally. Under heavy debugging or active background sync, rendering threads can stall waiting for logging I/O lock releases.<br>*Fix:* Use lock-free double-buffering or offload log format serialization to the flush thread. | Low | [ ] Proposed |
| 59 | main.cpp | Low | **Redundant EXIF parsing for cached items**<br>During playlist updates, EXIF metadata and capture date extraction is done synchronously before checking the local SQLite cache database status, causing slow directory sweeps.<br>*Fix:* Perform local cache database lookups first and skip EXIF checks for cached hits. | None | [ ] Proposed |
