# TODO - piTrove Bug Tracking

This file tracks identified bugs, errors, and architectural weaknesses in the piTrove codebase.

## Legacy Resolved Items

| ID | Component | Severity | Description | Status |
|---|---|---|---|---|
| 1 | scanner.cpp | High | Synchronous `stat` and `directory_iterator` calls during scans will block indefinitely if the NAS CIFS share hangs. | [x] Resolved |
| 2 | main.cpp (Watchman) | High | Watchman thread calls blocking `stat()` / `access()` on media directory, causing the thread to hang indefinitely on CIFS disconnects and stalling application shutdown. | [x] Resolved |
| 3 | preload.cpp | High | Background preload queue workers perform blocking file opens/decodes, causing threads to hang indefinitely on CIFS unresponsiveness and block graceful shutdown. | [x] Resolved |
| 4 | mqtt.cpp | High | Lack of subscriber reconnection watchdog: if `mosquitto_sub` drops connection or the broker restarts, the command pipe closes, thread exits, and MQTT is permanently disabled. | [x] Resolved |
| 5 | google_photos.cpp | Medium | Option injection and SSRF vulnerability in the Google Photos media downloader if `baseUrl` contains malicious parameters or targets private subnets. | [x] Resolved |

## Active Backlog (Audit Results)

The following bugs and architectural weaknesses were discovered during the codebase audit:

| ID | Component | Severity | Description & Proposed Fix | Breakage Risk | Status |
|---|---|---|---|---|---|
| 11 | preprocess.cpp | High | **Shell command argument unquoted**<br>In `get_video_metadata_ffprobe`, the path argument `escape_shell_arg(path)` is appended without surrounding quotes, causing it to break on filenames containing spaces or shell metacharacters.<br>*Fix:* Wrap it in single quotes: `+ " '" + escape_shell_arg(path) + "'"` | None | [x] Resolved |
| 12 | main.cpp | High | **Watchdog gateway check unquoted**<br>The gateway ping command `escape_shell_arg(gateway)` lacks single quotes, which can break or fail shell execution if the gateway contains special symbols/whitespace.<br>*Fix:* Wrap in single quotes: `+ " '" + escape_shell_arg(gateway) + "'"` | None | [x] Resolved |
| 13 | font_render.cpp | High | **Uncaught open font exception**<br>`TTF_OpenFont` failure throws a raw `std::runtime_error("Font load failed")` which is uncaught in `main.cpp`. This causes the slideshow to immediately crash at startup if the configured font is missing/unreadable.<br>*Fix:* Wrap font load calls in a try-catch block and fall back to the bundled `/app/src/fonts/DejaVuSansMono-Bold.ttf`. | None | [x] Resolved |
| 14 | transition.cpp | High | **Heap allocation churn**<br>`render_pixelate` allocates a new `std::vector<SDL_FRect> rects` on the heap *every frame* during active transitions, leading to severe heap churn and rendering lag on the Raspberry Pi.<br>*Fix:* Use `static thread_local std::vector<SDL_FRect> rects` and clear it on each call, matching the optimized dissolve transition. | None | [x] Resolved |
| 15 | http_server.cpp | Medium | **Loose MIME type suffix check**<br>`handle_preview` MIME type check uses `find(".png")` instead of checking the actual file suffix/extension. If a directory name contains `.png` (e.g. `/my.png.pics/photo.jpg`), the image will be incorrectly sent as `image/png` instead of `image/jpeg`.<br>*Fix:* Extract the file extension using `std::filesystem::path(path).extension()` and match that. | None | [x] Resolved |
| 16 | http_server.cpp | Medium | **Fragmented HTTP read**<br>`handle_client` uses a single socket `read()` call, failing to handle fragmented or slow HTTP request headers (common with slow clients or bad networks).<br>*Fix:* Read from socket in a loop until the header delimiter `\r\n\r\n` is found or timeout is reached. | None | [x] Resolved |
| 17 | mqtt.cpp | High | **Shutdown race / Undefined behavior**<br>`stop_mqtt_client` calls `pclose(g_mqtt_fp)` on the main thread while the subscriber thread is blocked on `fgets` using the same pointer. This causes a data race on the `FILE` handle and undefined behavior (crashes or hangs).<br>*Fix:* Use `fork` + `exec` directly to track the child PID and send `SIGTERM` before closing the file descriptor, avoiding shared handle state. | Low | [ ] Deferred |
| 18 | google_photos.cpp | High | **Missing curl request timeouts**<br>Curl synchronization commands lack connection/transfer timeouts. An unstable internet connection will cause the background sync thread to block indefinitely, hanging the app on shutdown.<br>*Fix:* Add `--connect-timeout 10 --max-time 30` to all curl command strings. | None | [x] Resolved |
| 19 | config.cpp | Medium | **Missing rotation bounds**<br>Display `rotation` values parsed from `config.toml` are not validated. Arbitrary values (e.g., `45` or `999`) pass through, causing undefined rendering behavior.<br>*Fix:* Validate and clamp the value to `0`, `90`, `180`, or `270`. | None | [x] Resolved |
| 20 | mpv_player.cpp | Medium | **Hardcoded close loop limit**<br>The file descriptor close loop in the child process is hardcoded up to `1024`, causing fd leaks if the system's maximum file descriptor limit is higher.<br>*Fix:* Determine limits dynamically using `sysconf(_SC_OPEN_MAX)`. | None | [x] Resolved |
| 21 | cache.cpp | Medium | **SQLite prepared statement bindings race**<br>Prepared statements bound with `SQLITE_STATIC` are never cleared. If strings go out of scope before the statement is re-bound/finalized, it creates a use-after-free vulnerability.<br>*Fix:* Invoke `sqlite3_clear_bindings` after `sqlite3_reset`. | None | [x] Resolved |
| 22 | util.cpp | Medium | **Blocking getaddrinfo on main thread**<br>`is_nas_online()` performs a blocking DNS lookup via `getaddrinfo()`. If DNS is offline/slow, the main rendering thread will freeze for up to 60 seconds.<br>*Fix:* Run the DNS lookup in a background thread or check local network interface gate status first. | Medium | [ ] Deferred |
| 23 | util.cpp | Medium | **Blocking lseek over network share**<br>`prefetch_video()` performs a synchronous `lseek` to the end of the file on the main thread. Doing this over CIFS/SMB can cause frame drops and transition stuttering.<br>*Fix:* Remove the size check/lseek or offload video prefetching to a background task thread. | None | [x] Resolved |
| 24 | http_server.cpp | Medium | **Sensitive credentials exposed in GET parameters**<br>Google Photos OAuth credentials (client_id, client_secret) are sent as query parameters in GET requests `/google_photos_setup`, leaking them in web server logs and browser history.<br>*Fix:* Redesign setup form to submit via `POST` requests and parse fields from request body. | Low | [x] Resolved |
| 25 | mqtt.cpp | Medium | **Credentials exposed in command line**<br>MQTT credentials and payloads are passed directly to `mosquitto_pub` CLI arguments, exposing secrets to local users via the process list (`ps aux`).<br>*Fix:* Pipe the payloads and passwords to stdin of `mosquitto_pub` or migrate to a library implementation. | Low | [x] Resolved |
| 26 | google_photos.cpp | Low | **Premature space check**<br>`std::filesystem::space` is called on `cache_dir` before verifying if the folder exists, causing initialization failures if the folder has not been created yet.<br>*Fix:* Run `create_directories` before checking available space. | None | [x] Resolved |
| 27 | blur.cpp | High | **Performance bottleneck**<br>`compute_matte_color()` performs a dense loop over every single pixel in the central crop (up to millions of iterations for large JPEGs), blocking threads needlessly.<br>*Fix:* Use step scanning (e.g. every 64th pixel) to compute average color instantly without sacrificing quality. | Low | [x] Resolved |
| 28 | config.cpp | Low | **Dead code setting**<br>The global configuration parameter `rotation` is parsed and stored, but completely ignored by the Modesetting KMSDRM rendering pipeline.<br>*Fix:* Document this as dead code or implement rotation in Modesetting DRM. | Low | [ ] Deferred |
| 29 | main.cpp | Medium | **Watchdog blanking legacy check**<br>Watchdog forced restart writes to `/sys/class/graphics/fb0/blank`, which does not exist or is ignored under modern KMSDRM graphic drivers.<br>*Fix:* Use Modesetting DPMS property controls or direct EGL/DRM blank calls. | None | [x] Resolved |
| 30 | tui.cpp | Medium | **TUI input freeze**<br>Incomplete or corrupted escape sequences can fill up the 256-byte TUI input buffer. Once full, the read call requests 0 bytes, freezing all TUI keystrokes permanently.<br>*Fix:* Discard the buffer contents if a sequence remains incomplete and the buffer reaches its maximum capacity. | None | [x] Resolved |
| 31 | http_server.cpp | Low | **Settings validation query parameter substring collision**<br>Settings validation matches using `request.find("transition_delay=")`. If a client sends a parameter containing that name (e.g. `other_param_transition_delay=`), it falsely triggers validation.<br>*Fix:* Extract query parameters using exact key lookup first. | None | [x] Resolved |
| 32 | http_server.cpp | Low | **Query parameter key substring collision**<br>`get_query_param` matches substring keys (e.g., finding `id=` inside `client_id=123`).<br>*Fix:* Scan parameters strictly starting with `?key=` or `&key=`. | None | [x] Resolved |
| 33 | http_server.cpp | Low | **Null-byte injection in percent decoder**<br>Percent decoder does not validate characters following `%`. Invalid percent encoding (e.g., `%00` or `%xx`) inserts a null byte or corrupts target strings.<br>*Fix:* Validate hex characters and reject/ignore invalid sequences. | None | [x] Resolved |
| 34 | mqtt.cpp | Medium | **Message payload truncation**<br>The subscriber thread uses a hardcoded 512-byte buffer for reading command payloads.
